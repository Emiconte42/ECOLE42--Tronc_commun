Pour info ce que j'ai vu pour l'instant : 
Une classe est un modèle qui décrit un type d'objet.
Un objet est une instance créée à partir d'une classe.
Les attributs sont les variables qui représentent les données d'un objet.
Les méthodes sont les fonctions qui permettent d'agir sur un objet.
private protège les données internes d'une classe.
public définit ce qui est accessible depuis l'extérieur de la classe.
L'encapsulation consiste à manipuler les attributs uniquement via les méthodes publiques.
Les getters permettent de lire la valeur d'un attribut privé.
Les setters permettent de modifier la valeur d'un attribut privé.
La classe Contact représente une fiche de contact contenant plusieurs informations.
Chaque objet possède son propre état, c'est-à-dire ses propres valeurs d'attributs.
Les méthodes modifient ou consultent l'état de l'objet auquel elles appartiennent.
Une classe peut contenir plusieurs attributs de types différents.
Un attribut peut être un autre objet, comme un Contact dans une autre classe.
Un attribut peut être un tableau d'objets, par exemple Contact _contacts[8];.
La classe PhoneBook possède un tableau de huit objets Contact.
Un tableau possède des indices qui commencent toujours à 0.
Le dernier indice d'un tableau de 8 éléments est 7.
Le tableau connaît sa taille, mais pas le nombre d'éléments réellement utilisés.
Le compteur _count mémorise le nombre de contacts enregistrés.
La prochaine case libre est toujours _contacts[_count] tant que le tableau n'est pas plein.
Un objet conserve son état entre les différents appels de ses méthodes.
