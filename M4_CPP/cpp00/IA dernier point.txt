1. Ex00 — Megaphone : ✅ TERMINÉ ET VALIDÉ
Programme qui reprend les arguments passés en ligne de commande, les affiche en majuscules, et affiche un message spécial si aucun argument n'est donné.
Notions vues et acquises :
#include <iostream> → std::cout, std::endl (remplace printf)
argc / argv (déjà connu depuis le C)
Boucle sur argv[i][j] caractère par caractère
toupper() de <cctype> — règle retenue : en C++, il faut toujours inclure explicitement le header d'une fonction utilisée, même si ça compile sans (pas de dépendances "cachées")
Piège identifié et évité : ne pas rajouter d'espace manuellement entre les arguments (ils en contiennent déjà si besoin, ex : " ! ")

2. Ex01 — My Awesome PhoneBook : 🔄 EN COURS
Deux classes à écrire : Contact (une fiche) et PhoneBook (carnet de 8 contacts max, pas d'allocation dynamique).
2.a Ce qui est acquis sur la classe Contact
Classe vs struct : une class est private par défaut, une struct est public par défaut — c'est la seule différence technique.
Encapsulation : cacher les attributs (private) et ne les exposer que via des fonctions publiques contrôlées (getters/setters).
Attribut : variable membre de la classe (convention utilisée : préfixe _, ex _first_name).
Getter : fonction publique qui lit un attribut sans le modifier.
Setter : fonction publique qui modifie un attribut (peut filtrer les valeurs invalides).
Le mot-clé const après les parenthèses d'une fonction membre : interdit à la fonction de modifier l'objet ; permet aussi d'appeler cette fonction sur un objet/référence constant(e). Règle retenue : toute fonction qui ne modifie rien devrait être const.
Passage de paramètre par const std::string & plutôt que std::string (évite une copie inutile) — notion vue, pas encore creusée en détail (lien avec le chapitre "Les références" de Skilleos).
Code déjà écrit et validé pour _first_name (à réutiliser comme modèle pour les 4 attributs restants) :

#include <iostream>
#include <string>

class Contact
{
    private:
        std::string _first_name;
        std::string _last_name;
        std::string _nick_name;
        std::string _phone_number;
        std::string _darkest_secret;
    public:
        void        setFirstName(const std::string &firstname)
        {
            _first_name = firstname;
        }

        std::string getFirstName() const
        {
            return _first_name;
        }
};

2.b Ce qu'il reste à faire sur Contact (pas encore vu / pas encore fait)
Écrire les 4 getters/setters restants (_last_name, _nick_name, _phone_number, _darkest_secret) sur le même modèle que _first_name.
Le constructeur : comment donner des valeurs de départ à un Contact au moment de sa création (Contact c; puis remplissage via setters, ou constructeur avec paramètres). Pas encore abordé du tout.
Éventuellement le destructeur (pas indispensable pour cet exercice, Contact ne gère pas de mémoire dynamique).
2.c Ce qu'il reste à faire sur PhoneBook (pas commencé)
Créer la classe PhoneBook qui contient un tableau fixe de 8 Contact maximum (pas de new, allocation dynamique interdite dans cet exercice).
Logique d'ajout : si un 9e contact est ajouté, remplacer le plus ancien (comportement circulaire).
Boucle principale dans le main : lire les commandes ADD, SEARCH, EXIT au clavier (std::cin).
ADD : demander les 5 champs un par un, refuser un champ vide.
SEARCH : afficher un tableau à 4 colonnes (index, prénom, nom, surnom), chaque colonne large de 10 caractères, alignée à droite, tronquée avec un . si trop long ; utile ici : <iomanip> (std::setw, std::setfill — pas encore vu, un indice du sujet).
Puis demander un index et afficher la fiche complète du contact choisi (gérer l'index invalide).
EXIT : quitter le programme.
